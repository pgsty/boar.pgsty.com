Boar `v0.2.0` 是源码 `38f0a546fb0b1d6e3c7bf37fb422d68e26fc0544` 上冻结的 Fusion
**验收基线**，结合原生 Patroni Control、类型化
etcd/PostgreSQL Provider、Fleet Aggregation、Durable Approval/Job/Audit Governance、
Pigsty Operation 与统一双语 Web Experience。

## 亮点

- 原生实现全部 19 条 Patroni CLI，Runtime 不依赖 Python。
- SDK、API、Audit 与 Web UI 统一表达 Success、Rejection、Conflict、Unreachable、
  Cancellation 与 `UNKNOWN/MAYBE_SENT/UNCONFIRMED`。
- 三层 Scope Fleet Discovery/Watch，以及受控 100 Scope/500 Member Performance Gate。
- Durable Encrypted Plan Artifact、Current Authorization、Terminal Job/Audit Convergence 与
  Startup No-replay Recovery。
- Pigsty Inventory Import、Desired/Recorded/Actual State、Allowlisted Planning 与隔离真实
  Control-plane Lab Evidence。
- 在 PostgreSQL `18.4` 与四节点 Lab 上完成真实 Chromium Journey。

## 历史验收制品

验收制品合同精确包含：

```text
boar-v0.2.0-linux-amd64.tar.gz
boar-v0.2.0-linux-arm64.tar.gz
boar-v0.2.0.cdx.json
boar-v0.2.0-build-receipt.json
SHA256SUMS
SHA256SUMS.sig
RELEASE-PUBLIC-KEY.pem
```

每份归档包含 Embedded Frontend、`LICENSE`、`README.md` 与一个 Static Boar Binary。
Build 使用 Canonical Tar Metadata、`SOURCE_DATE_EPOCH`、`-trimpath`、`-buildvcs=false`
与空 Go Build ID。同一平台两次构建必须 Byte-identical。

先通过带外渠道验证可信 Ed25519 Public-key Fingerprint，再执行：

```bash
openssl pkeyutl -verify -pubin -inkey RELEASE-PUBLIC-KEY.pem \
  -rawin -in SHA256SUMS -sigfile SHA256SUMS.sig
sha256sum -c SHA256SUMS
jq -e '.bomFormat == "CycloneDX" and .specVersion == "1.6"' \
  boar-v0.2.0.cdx.json
```

历史 Gate 会先拒绝 Tampered Archive、Missing SBOM、Extra Artifact 与 Modified Signature，
再以数字 UID/GID `65532` 在 Scratch Image 中运行两个架构，并连接固定 PostgreSQL Service。

## 迁移背景

如果仍在运行这个验收快照，其 Metadata Schema 包含前向 Migration `0001` 至 `0010`。
先备份精确 `boar`
Database、排空 Confirmed Write、记录所有 UNKNOWN，执行 `boar migrate`，验证 Migration
Ledger 后再重启。

按照[安装、升级与恢复](/zh/docs/admin/upgrade-recovery/)操作。

## 破坏性变化

- 公共 Fusion API Baseline 为 `v0.2.0` / `v1alpha1`；Caller 使用 Typed Target/Result
  Contract，不再依赖私有 Legacy Structure。
- Confirmed Mutation 要求精确 Plan/Action/Target Identity，并可能返回 Durable UNKNOWN，
  而不是不安全重试。
- Configuration Source 与 Credential File 强制 Canonical Path、Owner、Mode、No-symlink、
  Size 与 Precedence Rule。
- Encrypted PostgreSQL Client Private Key 在 Decrypt/KDF 前直接拒绝。
- Release Container 使用数字 UID/GID `65532`，不以 Root 运行。

## 兼容性

已审查矩阵包含 Go `1.26.6`、Node.js `26.4.0`、PostgreSQL `18.4`、Patroni `4.0.7`
与固定 `4.1.0` Source Lane，以及 etcd `3.5.33`、`3.6.14`、`3.7.1`。Source Pin 与
Approved Deviation 见[兼容矩阵](/zh/docs/reference/compatibility/)。

## 已知限制

- Browser Evidence 覆盖 Chromium，不包括 Firefox/WebKit。
- Claude Code 不在 Scratch Release Image 内；缺失时 Assistant Health 有界降级。
- Rollback 依赖 Backup/Restore，没有 Down-migration。
- Hardened Provider Subset 之外的 Ambient libpq 行为不在承诺中。
- Local Evidence 不能替代要求的具名 Remote-CI Run。

## 证据边界

TLS/Auth/Source Check、Patroni Control、Fleet Performance、Pigsty Lab、Browser E2E、
Packaging 与 Remote CI 是独立 Evidence Lane，任何一条通过都不能合成另一条。
